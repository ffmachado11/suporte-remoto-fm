# Suporte Remoto FM

Cliente Windows personalizado pela FM Tecnologia, baseado no RustDesk 1.5.3.

O cliente é pré-configurado para a infraestrutura própria da FM Tecnologia e usa a identidade
visual oficial da empresa. O código-base permanece sob a licença AGPL-3.0 do projeto RustDesk.

## Compilação

O workflow `Build Suporte Remoto FM` gera o instalador Windows x64 de forma reproduzível pelo
GitHub Actions. O artefato final é publicado junto com seu hash SHA-256.

## Licença e código-fonte

Este repositório contém o código-fonte correspondente à versão distribuída. As alterações da FM
Tecnologia não removem nem substituem os direitos e avisos da licença original AGPL-3.0.

Projeto original: https://github.com/rustdesk/rustdesk
